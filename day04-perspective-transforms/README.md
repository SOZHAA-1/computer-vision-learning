# 第 4 天：平移与透视变换

## 今日目标

理解图像位置和视角为什么能被矩阵变换改变，并完成一次简单的透视矫正。

## 完成的练习

1. **平移图片**：用 `shift_image.py` 把图片向右、向下移动，观察空出来的黑色区域。
2. **比较平移方向**：用 `shift_compare.py` 同时比较右下、左上和右上平移。
3. **透视变换**：用 `perspective_transform.py` 让图片产生轻微、自然的倾斜感。
4. **强度对比**：用 `perspective_compare.py` 对比轻微透视和明显透视的差异。
5. **透视矫正**：用 `perspective_correction.py` 先模拟倾斜，再把画面拉回接近原图的状态。

## 核心概念

- `x` 控制左右平移，`y` 控制上下平移。
- 平移后出现黑边是正常现象：原来的像素位置被移走后，没有内容来填充。
- 透视变换通过调整图片的四个角，制造从不同角度拍摄的效果。
- 透视矫正是反向把倾斜画面的四个角映射回规则的矩形，常用于文档扫描、白板照片校正等场景。

## 今日结论

- 轻微透视更自然，既能看出角度变化，也不会让画面显得太夸张。
- 透视矫正后，结果图会比倾斜图更接近原图。

## 文件说明

- `shift_image.py`：单次平移。
- `shift_compare.py`：不同平移方向对比。
- `perspective_transform.py`：轻微自然的透视变换。
- `perspective_compare.py`：轻微与明显透视效果对比。
- `perspective_correction.py`：模拟倾斜并进行透视矫正。
