# 第 2 天：图像几何变换

## 已完成的练习

1. 图片缩放：将图片缩小到原来的一半。
2. 图片旋转：将图片绕中心旋转 45 度。
3. 图片裁剪：保留图片中央 60% 的区域。
4. 效果对比：将原图、缩放、旋转和裁剪放在同一张图中比较。
5. 图片翻转：比较原图、左右翻转和上下翻转。

## 今天学到的核心流程

```text
原始图片 → 几何变换 → 观察结果 → 保存新图片
```

## 三种核心变换

- 缩放：改变图片尺寸。
- 旋转：改变图片方向。
- 裁剪：保留图片的指定区域。

## 为什么有用

这些变换能帮助我们理解图片的空间变化；在后续训练视觉模型时，它们也可以用来扩充训练数据。
