# 第 3 天：颜色空间与颜色提取

## 已完成的练习

1. 将图片从 BGR 转换为 HSV，并观察色相、饱和度和亮度通道。
2. 对比自然光与霓虹光人像的 HSV 信息。
3. 对比多种色相偏移，找到较自然的颜色变化。
4. 对比多种饱和度倍率，观察颜色从淡到鲜艳的变化。
5. 对比多种亮度倍率，观察图片从暗到亮的变化。
6. 将选出的参数综合应用到人像调色中。
7. 使用颜色掩码提取蓝紫色区域，并进一步收窄为纯蓝色范围。

## 今天学到的核心流程

```text
原始图片 → 转换到 HSV → 单独调整或筛选一个颜色通道 → 对比结果 → 记录结论
```

## 核心概念

- **Hue（色相）**：颜色类型，例如蓝、紫、红。
- **Saturation（饱和度）**：颜色有多鲜艳。
- **Value / Brightness（亮度）**：画面有多明亮。
- **Color Mask（颜色掩码）**：按颜色范围选出指定区域。

## 最终参数选择

- 色相偏移：5
- 饱和度倍率：1.0
- 亮度倍率：1.0

这组设置在霓虹人像上保留了自然肤色，同时带来轻微的颜色变化。

## 颜色提取结论

较宽的蓝紫范围会混入相近颜色；收窄到纯蓝范围后，杂色减少，只保留了主要蓝色光线区域。
