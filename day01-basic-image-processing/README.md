# 第 1 天：基础图像处理

## 已完成的练习

1. 读取并显示一张彩色图片。
2. 将彩色图片转换为灰度图。
3. 使用高斯模糊让图片变得更平滑。
4. 使用 Canny 算法提取图片边缘。
5. 对比不同 Canny 参数下的边缘效果。
6. 使用阈值分割生成黑白剪影图。
7. 对比不同阈值对黑白结果的影响。

## 今天学到的核心流程

```text
原始图片 → 图像处理算法 → 显示并保存新图片 → 调整参数并比较结果
```

## 核心概念

- **灰度化**：把彩色图片变成黑白灰度图片。
- **模糊**：降低细小噪声，让图片更平滑。
- **边缘检测**：寻找物体轮廓。
- **阈值分割**：根据亮度把图片分成黑白两部分。

## 为什么有用

这些基础处理是许多计算机视觉任务的前置步骤。后续做目标检测、分割和模型训练时，都经常需要先理解图片的颜色、边缘和区域信息。
