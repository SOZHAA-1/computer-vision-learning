# 16 周计算机视觉学习计划

这是一个面向零基础学习者的实践型计划。每周预计投入 12–14 小时：周一至周五每天 1.5–2 小时，周末安排约 4 小时做综合练习和复盘。

## 每周学习节奏

- **周一至周五**：30 分钟理解一个小概念，60 分钟跟着运行或修改代码，最后 15–30 分钟记录结果。
- **周末**：约 2 小时完成综合练习，约 1 小时复盘，约 1 小时预习或整理 GitHub。
- **每周成果**：至少保留一段可运行代码、一张结果图或一篇实验记录。

## 学习路线

| 周数 | 主题 | 主要内容 | 本周成果 |
| --- | --- | --- | --- |
| 第 1 周 | Python 与 OpenCV 入门 | 读图、显示、灰度化、模糊、边缘检测、阈值分割 | 图像处理基础练习 |
| 第 2 周 | 图像几何变换 | 缩放、旋转、裁剪、翻转、参数对比 | 几何变换对比图 |
| 第 3 周 | 经典图像处理 | 卷积、滤波、形态学操作、轮廓检测 | 简单图像清理实验 |
| 第 4 周 | 特征与图像匹配 | 角点、ORB/SIFT、特征匹配、RANSAC | 文档扫描或图片拼接小项目 |
| 第 5 周 | 深度学习基础 | PyTorch、张量、数据集、训练循环、损失函数 | 第一个 PyTorch 训练脚本 |
| 第 6 周 | CNN 图像分类 | 卷积神经网络、池化、激活函数、分类结果 | CIFAR-10 分类模型 |
| 第 7 周 | 模型训练与评估 | 过拟合、数据增强、准确率、混淆矩阵 | 分类模型改进实验 |
| 第 8 周 | 分类小项目 | 收集小数据集、训练、测试、分析错误 | 完整图像分类项目 |
| 第 9 周 | 目标检测基础 | 边界框、IoU、NMS、mAP 的概念 | 检测结果可视化 |
| 第 10 周 | YOLO 实战 | 使用预训练 YOLO、标注小数据集、推理与训练 | 自定义目标检测练习 |
| 第 11 周 | 语义分割 | 像素级分类、掩码、U-Net 基础 | 简单分割结果 |
| 第 12 周 | 分割项目 | 数据准备、训练、评估、结果对比 | 一个分割小项目 |
| 第 13 周 | 进阶方向一 | 选择 OCR、目标跟踪或姿态估计中的一个方向 | 方向体验项目 |
| 第 14 周 | 进阶方向二 | 迁移学习、视觉 Transformer 或模型部署基础 | 进阶实验记录 |
| 第 15 周 | 毕业项目准备 | 选题、数据集、实验计划、仓库结构 | 项目计划与数据准备 |
| 第 16 周 | 毕业项目与作品集 | 训练、评估、可视化、README、复盘 | 可展示的 GitHub 作品集 |

## 学习原则

1. 先让代码运行并观察图片变化，再逐步理解代码。
2. 每次只改一个参数，比较前后效果。
3. 每一天的文件夹都保留一个 README，说明当天主题、练习、核心概念和收获。
4. 把代码、图片和结论一起保存到当天文件夹。
5. 每完成一周，把成果推送到 GitHub，形成持续积累的作品集。
